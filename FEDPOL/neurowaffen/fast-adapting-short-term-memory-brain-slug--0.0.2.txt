Big picture first (CS-style mental model)

Think of the brain’s working-memory system like a small, distributed in-RAM state machine that supports active tasks. It has:

    a small capacity (a few items / chunks),

    gating and attention subsystems that decide what gets promoted into the RAM-like workspace,

    priority/valence tags (emotional salience) that change retention and retrieval,

    neuromodulatory controllers (biochemical signals: noradrenaline, dopamine, acetylcholine, cortisol) that change latency, noise, and gating thresholds on short time scales.

A “flooding” attack aims to saturate that RAM quickly with attacker-controlled content at moments when the gating/attention filters are weakened, or to bias the priority tags so attacker content dominates recall. The most effective strategy (in principle) is therefore to 1) target the parts of the system responsible for gating/maintenance + salience tagging, and 2) adjust the neuromodulatory state so the system becomes more distractible and biased toward emotionally-salient items.

2) Mechanisms by which “flooding” impairs short-term memory (functional dynamics)

These are the causal/physiological mechanisms (not how to induce them):
Capacity saturation and interference

    Working memory holds a small number of active items. Presenting many salient items rapidly causes interference: new items either overwrite the same representational slots or induce competition that makes retrieval noisy and error-prone.

Attentional capture and salience bias

    Sudden, novel, or emotionally salient inputs activate amygdala and parietal attentional systems, diverting resources away from ongoing goals. Items paired with high arousal are more likely to be encoded and retained.

Neuromodulatory state changes

    Fast changes in noradrenergic and cholinergic tone alter signal-to-noise ratio in prefrontal circuits. For example, phasic noradrenaline increases “gain” and responsiveness to salient inputs but tends to impair fine executive control — i.e., the system becomes reactive rather than deliberative.

Failure of top-down inhibition

    Prefrontal inhibitory control normally suppresses distractors; stress and neuromodulator shifts can transiently reduce that inhibition, letting distractors enter WM.

State-dependent encoding and retrieval

    Items encoded under a particular internal state (high arousal, anxiety) are more likely to be retrieved when the same state recurs. An adversary could, in principle, both encode items in a stressed state and later re-induce that state to bias recall.

Disruption of consolidation

    Rapid, repeated salience-tagged items can interfere with hippocampal binding processes that would otherwise stabilize safety-relevant memories; net effect: safety plans fail to consolidate and are more easily forgotten.
